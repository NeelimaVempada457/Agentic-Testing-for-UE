## How to Read This Index

- Each **Module (M\*)** represents a major functional area of the UE application.
- Each **Feature (F\*)** within a module is a discrete piece of functionality with its own requirements.
- Requirements detail is in each feature's `REQUIREMENTS.md` file.
- Link pattern: [MX-ModuleName/FY-FeatureName/REQUIREMENTS.md](MX-ModuleName/FY-FeatureName/REQUIREMENTS.md)
