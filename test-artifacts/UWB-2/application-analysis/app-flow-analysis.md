## User Flows Observed

### Flow 1: View Summary Statistics
1. User navigates to `/submissions`
2. Summary bar renders with 6 stat cards
3. Metrics are computed from live submission data
4. Read-only metrics (Avg. Time in Queue, SLA At Risk) are displayed but not interactive

### Flow 2: Filter by Summary Stat
1. User clicks a summary bar card (e.g. "Awaiting Info")
2. Card shows pressed state
3. Table below filters to show only submissions matching that status
4. Result count updates

### Flow 3: Export Submissions
1. User clicks Export button in header
2. Current filtered submission list downloads (format TBD)

### Flow 4: Create New Submission
1. User clicks "New Submission" button
2. Navigates to new submission creation form
