- **Impact:** All 5 acceptance criteria for summary bar are untestable as specified; requires BA sign-off on updated metric set

### D-04 — Bound Premium (YTD) Missing (MEDIUM)

- **Observed:** No "Bound Premium" stat card exists in the live summary bar
- **Impact:** AC-03 (Bound Premium formatted as currency) cannot be verified
