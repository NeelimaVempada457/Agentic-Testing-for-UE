## User Flows Observed

### Flow 1: Browse Submissions Table
1. User navigates to `/submissions`
2. Table loads showing 5 rows per page, 18 total
3. Default view: My Queue tab active, sorted by most recently created (implied)

### Flow 2: Click Row to View Detail
1. User clicks anywhere on a row (or account name hyperlink)
2. Browser navigates to `/submission/{SUB-ID}` — detail page
3. URL updates e.g. `/submission/SUB-7842`

### Flow 3: Sort Column
1. User clicks a sortable column header (Premium, Need By, Effective)
2. Arrow toggles ascending/descending
3. Table re-renders sorted by that column

### Flow 4: Paginate
1. User clicks page number (1–4) or Next/Previous
2. Table updates to show next 5 rows
3. Footer shows "Showing X–Y of N submissions · Page Z of M"

### Flow 5: Search
1. User types in "Search member, broker, sub ID…" box
2. Table filters in real-time

### Flow 6: Apply Filter
1. User clicks "Filters" button
2. Filter panel opens
3. Table filters by selected criteria
