## Per-Discrepancy Details

### D-01 — Row Click URL Pattern (HIGH)
- **Requirement:** "Clicking a row navigates to the Submission Detail page; URL updates to /submissions/{SUB-ID}"
- **Observed:** Clicking row for SUB-7842 navigates to `/submission/SUB-7842` (singular path segment)
- **Impact:** AC-06 fails as written; URL assertion tests must use `/submission/` not `/submissions/`
- **Severity:** High — affects automated test URL assertion for every row-click test

### D-02 — Column Order (MEDIUM)
- **Requirement:** Column order — ...Stage, **Premium**, Underwriter, Appetite, Need By, Effective
- **Observed:** Column order — ...Stage, **Underwriter**, Appetite, Premium, Need By, Effective
- **Impact:** Column-index–based assertions will fail; column-header–based assertions are fine
- **Severity:** Medium

### D-03 — Additional Sortable Column (LOW)
- **Requirement:** Sortable columns: Need By and Effective (Age was struck through)
- **Observed:** Premium, Need By, and Effective all have ↑↓ sort buttons
- **Impact:** Premium sorting is an undocumented positive feature; test scope expands slightly
- **Severity:** Low

### D-04 — Stage Badge "Pending Info" Not in Spec (MEDIUM)
- **Requirement:** Stages referenced: New (Grey), In Review (Amber), Bound (Green) per UWB-1 colour spec
- **Observed:** Rows show "Pending Info" stage which has no defined colour or label in the spec
- **Impact:** Stage colour-coding AC cannot be fully verified; "Pending Info" needs BA clarification
- **Severity:** Medium

### D-05 — New Submission Button Label (MEDIUM)
- **Requirement:** Button labelled "+ New Submission"
- **Observed:** Button reads "New Submission" (+ icon is rendered as an SVG img element, not as text)
- **Impact:** Text-based assertions checking for "+" will fail; use "New Submission" text assertion instead
- **Severity:** Medium
