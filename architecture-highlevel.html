Design Principles
🔒
Human-in-the-Loop
FINAL_APPROVE is the only Jira trigger. No automated bug creation.
🔗
Traceability First
Full chain: AC → Test → App → Bug → Screenshot → Jira.
📸
Evidence-Driven QA
Every discrepancy has DISC-NNN screenshot auto-attached.
🎯
Single Bug Per Cycle
One consolidated Jira bug per story. Zero noise.
